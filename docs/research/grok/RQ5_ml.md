## 2. Lab-in-the-loop cycle

Recursion/Valence, Figure 2 A–E:

1. Virtual cell **predicts** the functional response to a perturbation.
2. It **explains** the prediction via mechanistic molecular interactions.
3. **Agents design** experiments that seek to **falsify** the prediction.
4. Real labs **execute** those experiments.
5. The model **updates** when a hypothesis is falsified.

Figure 5 title: “Virtual cells are falsifiable theories of cellular
biology.”

Strongest circular composition in the packet: this **five-node closed
cycle**. Use it as process grammar (RQ7 blueprint 3), not as the hero
identity.
